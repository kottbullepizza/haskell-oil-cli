# Haskell Brent Crude Oil price CLI

Pulls the current Brent crude price. Used as a Fastfetch module.

Get a free key at oilpriceapi.com, then add to `~/.bashrc`:

export OILPRICE_API_KEY="your-key-here"

To use it as a fastfetch module, don't forget to add it as a command in fastfetch/config.jsonc modules
